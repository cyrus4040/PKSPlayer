# PK'S Player
MX Player-style video player (Kotlin, Jetpack Compose, Media3 ExoPlayer). Lime green + black.

Build: push to GitHub (main) -> Actions -> "Build APK" -> download artifact `PKSPlayer-v<version>` (contains `PKSPlayer-v<version>.apk`). Bump `versionName`/`versionCode` in app/build.gradle.kts for every update..
Local: `gradle assembleDebug` (JDK 17, Gradle 8.7).
